# Universal Workspace UI

Universal Workspace UI is a Flutter package that provides a collection of reusable UI components following the Universal Workspace design system. These components are designed to be consistent, accessible, and easy to use.

## Features

- **Design System Components**: Buttons, text fields, and more UI components that follow the Universal Workspace design system
- **Theming**: Consistent theming across all components with light and dark mode support

## Installation

Add the following to your `pubspec.yaml` file:

```yaml
dependencies:
  universalworkspace_ui: ^1.0.0
```
